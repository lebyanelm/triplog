# Trip Log

Offline-first trip logger (PWA) for Done Deal property fieldwork: start/end of day, GPS kilometres, a declaration per leg, OpenStreetMap navigation and arrival notes, synced to Google Sheets through a Google Apps Script web app.

Live app: https://lebyanelm.github.io/triplog/

See [SETUP.md](SETUP.md) for setup (Apps Script deploy, Add to Home Screen, Settings).

No secrets are stored in this repo. The sync token is entered in the app's Settings on the phone.
